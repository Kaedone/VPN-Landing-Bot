# AdultVPN — Защищенный VPN для моделей и стримеров

Конвертящий лендинг-воронка для привлечения adult-креаторов, вебкам-моделей (OnlyFans, Fansly, StripChat, Chaturbate, BongaCams) с переходом в Telegram-бота `@AdultVPN_bot`.

## Ключевые возможности
- **Интерактивный экспресс-аудит безопасности**: диагностика уязвимостей стримера (Зеркала, Shine Browser со скрытым криптомайнером, отсутствие Kill Switch в обычных VPN).
- **Секция Kill Switch**: наглядная демонстрация защиты от слива реального домашнего IP при микрообрывах Wi-Fi во время трансляций. Инструкция для клиентов **Happ** и **INCY**.
- **Тарифная сетка**: 7 дней (79₽), 30 дней (199₽), 90 дней (499₽), 180 дней (899₽), 365 дней (1499₽), Семейный тариф (349₽), Обход глушилок (139₽).
- **Оплата**: поддержка **Telegram Stars ⭐** для полной конфиденциальности без выписок банков.
- **Встроенная панель настроек**: изменение юзернейма бота, стартовых UTM-параметров и цен прямо в интерфейсе с сохранением в браузере.
- **Разделы доверия**: «Честно о границах VPN» и «Проверка утечек IP» (Iphey.com, DNSLeakTest).

## Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшна (Cloudflare Pages, Vercel, VPS)
npm run build
```

Папка сборки: `dist/`
